# 📊 AdventureWorks Sales Performance Dashboard

## 📌 Project Overview
An interactive Power BI dashboard built to analyze AdventureWorks sales data and identify business performance trends.

## 🎯 Project Objectives
- Analyze sales and revenue performance.
- Identify top-performing products.
- Track sales trends.
- Generate actionable business insights.
- Support data-driven decisions.

## 🛠️ Tools & Technologies
- Power BI Desktop
- Power Query
- DAX
- Data Visualization
